# Paradise Nursery

Paradise Nursery is an e-commerce React application designed for plant lovers. Browse a curated collection of house plants, filter by category, and manage your shopping cart using Redux Toolkit state management.

## Features
- **Landing Page**: Landing view with an immersive background image and landing text about the company.
- **Product Listing**: Explore plants categorized by type with options to add items to the cart.
- **Shopping Cart**: View added items, dynamically adjust quantities, calculate total costs, and clear items.
- **State Management**: Built with Redux Toolkit (`@reduxjs/toolkit` and `react-redux`).

## Setup and Run
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` or `npm start` to start the application.
